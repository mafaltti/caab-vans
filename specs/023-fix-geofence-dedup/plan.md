# Implementation Plan: Fix Geofence Duplicate Stop Passing

**Branch**: `023-fix-geofence-dedup` | **Date**: 2026-03-02 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/023-fix-geofence-dedup/spec.md`

## Summary

Fix a bug in `inferStopProgress()` where entering the geofence of a repeated stop location (e.g., CAAB appearing at 07:00, 09:00, 11:00) marks ALL pending occurrences as "passed" instead of just the first one. The fix adds two guards to the geofence loop: (1) coordinate deduplication — only the first pending occurrence per coordinate pair is marked per invocation, and (2) a 30-minute time window — stops whose scheduled time is more than 30 minutes in the future are skipped.
