# Data Model: OSRM Route-Based ETA

**Feature**: 037-osrm-eta-baseline
**Date**: 2026-03-04

## Database Changes

**None.** This feature requires no schema migrations. All data flows through:
- Existing tables (route_run_stops, van_location_pings, vans) for reading
- A new JSON file for correction factor storage

## Existing Entities (Read-Only)

### route_run_stops (used by nightly refinement script)

| Field | Type | Usage |
|-------|------|-------|
| run_id | uuid | FK to route_runs |
| schedule_entry_id | uuid | FK to schedule_entries |
| status | text | "pending" / "passed" |
| passed_at | timestamptz | Actual arrival time — compared against predicted ETA |

### vans (used by ETA calculation)

| Field | Type | Usage |
|-------|------|-------|
| last_lat | double | Raw GPS latitude |
| last_lng | double | Raw GPS longitude |
| last_speed_mps | double | GPS speed in m/s — primary speed source |
| snapped_lat | double | OSRM-snapped latitude (preferred over raw) |
| snapped_lng | double | OSRM-snapped longitude |
| location_updated_at | timestamptz | Freshness check |

### schedule_entries (used by ETA calculation)

| Field | Type | Usage |
|-------|------|-------|
| id | uuid | Stop identifier |
| time | text | Scheduled time (HH:mm) |
| stop_lat | double | Stop latitude — destination for OSRM route |
| stop_lng | double | Stop longitude |

## New Entities

### Time Factors File (`data/time-factors.json`)

Generated by nightly script. Read by `computeEta()` at runtime.

```json
{
  "generatedAt": "2026-03-04T23:30:00-03:00",
  "observationDays": 30,
  "minObservations": 20,
  "global": {
    "weekday": {
      "6": 1.05, "7": 1.35, "8": 1.40, "9": 1.15,
      "10": 1.0, "11": 1.0, "12": 1.0, "13": 1.0, "14": 1.0, "15": 1.0,
      "16": 1.10, "17": 1.35, "18": 1.30, "19": 1.05
    },
    "saturday": {
      "7": 1.0, "8": 1.05, "9": 1.10, "10": 1.05,
      "11": 1.0, "12": 1.0, "13": 1.0, "14": 1.0, "15": 1.0,
      "16": 1.0, "17": 1.05, "18": 1.05
    },
    "sunday": {}
  },
  "routes": {
    "route-uuid-1": {
      "weekday": { "7": 1.50, "8": 1.55 }
    }
  }
}
```

**Schema**:
- `global.<dayType>.<hour>` → correction factor (number, default 1.0)
- `routes.<routeId>.<dayType>.<hour>` → per-route override (takes precedence over global)
- Hours without entries default to factor 1.0
- File is optional — missing file → hardcoded defaults used

### Hardcoded Default Factors (in code)

Seeded defaults for day-one deployments, before any data exists:

| Day Type | Hours | Factor | Rationale |
|----------|-------|--------|-----------|
| weekday | 06 | 1.05 | Light early traffic |
| weekday | 07 | 1.35 | Morning rush building |
| weekday | 08 | 1.40 | Peak morning rush |
| weekday | 09 | 1.15 | Rush easing |
| weekday | 10-15 | 1.0 | Off-peak |
| weekday | 16 | 1.10 | Afternoon building |
| weekday | 17 | 1.35 | Evening rush |
| weekday | 18 | 1.30 | Evening rush |
| weekday | 19 | 1.05 | Rush easing |
| saturday | all | 1.0-1.10 | Minimal congestion |
| sunday | all | 1.0 | No correction |

## Data Flow

```
Request time (hot path):
  van position (snapped_lat/lng + speed) ──┐
  next stop (stop_lat/lng) ────────────────┤
                                           ▼
                                   OSRM /route ──→ road distance (meters)
                                           │         ↓ (fallback: haversine × 1.3)
                                           ▼
                                   road distance / GPS speed = base ETA
                                           │
                                           ▼
                              time-factors.json ──→ correction factor
                              today's completed runs ──→ recency factor
                                           │
                                           ▼
                                   base ETA × blended factor = final ETA

Nightly (cold path):
  route_run_stops.passed_at ──┐
  schedule_entries.time ──────┤
  van_location_pings ─────────┤
                              ▼
                    compute-time-factors.ts
                              │
                              ▼
                    data/time-factors.json (updated)
```
